## 🚀 Key Interactive Features

### 1. 📊 Signature Interactive Bar Chart (Hero)
* Visual manifestation of the reference image featuring rounded charcoal pillars and the towering signature **Amber bar**.
* Interactive hover inspection displaying real system benchmarks: AST logic judges, OWLv2 vision models, optical flow inlier ratios, and multi-agent routing telemetries.
* Hand-drawn *"Over 12K+ Verified Mappings"* cursive annotation with organic arrow.

### 2. 🧠 Live Multi-Agent & Verification Simulator
* An interactive simulation lab where visitors and recruiters can execute real-world scenarios:
  * **Scenario 1:** Multi-Agent NLP-to-SQL (Financial P&L variance across multi-tenant databases).
  * **Scenario 2:** Papertrail self-validating invoice OCR with arithmetic reconciliation and cost-gated AI calls.
  * **Scenario 3:** Bar Vision zero-shot video inventory with OWLv2 and optical flow camera pose recovery.
* Live step-by-step telemetry terminal showing AST parsing, MCP JSON-RPC database brokers, Key Vault short-lived JWTs, and deterministic invariant critics.

### 3. 🕹️ Playable Arcade Mini-Game: "Agentic Token Defender"
* A retro-modern browser mini-game accessible from the floating nav chip or `Play Arcade` button.
* Built on HTML5 Canvas + Web Audio API synthesizer (zero external audio files needed).
* Steer an Agent Drone, collect green **Embedding Tokens** (+100) and golden **MCP Keys** (+250 for temporary shield), and blast red **Taxonomy Drift Bugs** and **Hallucinations**!
* Tracks high scores locally and triggers confetti upon victory!

### 4. 📂 In-Depth Flagship Case Studies
* **AI Financial Assistant (Paperchase):** 6 specialist agents, 5 supporting LLMs, 4 memory tiers, and 3 independent verification layers.
* **Papertrail IDP (Paperchase):** 60% runtime cut (52s to 20s), arithmetic reconciliation, and ~$0.03 unit economics.
* **GL Master Mapping (Paperchase):** 36,500 LOC sole-ownership platform, resolving a silent 79% taxonomy drift across 12,087 stored records.
* **Bar Vision (Paperchase):** OWLv2 zero-shot detection, optical flow RANSAC camera tracking (0.41 -> 0.95 inlier ratio), and 2D CNN liquid regression.
* **Enterprise Copilots (atQor):** Promoter's Copilot, Manufacturing Equipment Copilot, and Corporate Visitor Management.

## 💻 Local Development

### 1. Install dependencies
```bash
npm install
```

### 2. Start local development server
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```

### 4. Preview production build locally
```bash
npm run preview
```

## 🌐 One-Click Deployment
This project is production-ready and can be deployed anywhere with a single click:

* **Vercel:** Run `npx vercel` or connect your GitHub repository.
* **Netlify:** Connect repo, set build command to `npm run build` and publish directory to `dist`.
* **Azure Static Web Apps:** Connect repo with `app_location: "/"`, `output_location: "dist"`.
* **GitHub Pages:** Deploy the generated `dist` folder.
